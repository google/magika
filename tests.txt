Magika PyO3 Verification & Testing Plan
========================================

Phase 1: Local Development & Workspace Checks (On This Machine)
---------------------------------------------------------------
Verify that local repository toolchains (`uv`, `cargo`) and in-process
Python bindings work as expected.

1. Verify `uv run magika` invokes the native Rust CLI:
   $ uv run --project python magika --version
   # Expected: magika 1.1.1-dev standard_v3_3 (Rust binary output format)

   Verify that it executes the compiled ELF binary, NOT a Python script:
   $ file $(uv run --project python which magika)
   # Expected: ELF 64-bit LSB pie executable ... (not Python script)

2. Run Python test suite:
   $ cd python
   $ uv run pytest tests/test_magika_python_module.py -k "not test_magika_module_with_big_file"
   # Expected: 22 passed, 1 skipped, 1 deselected (fast run in ~3s)
   # Or run full suite: uv run pytest tests/ (23 passed, 1 skipped)

3. Verify linters and type checkers:
   $ cd python
   $ uv run ruff check
   $ uv run ruff format --check
   $ uv run mypy src/magika
   # Expected: All checks pass with 0 errors

4. Quick smoke test in Python REPL:
   $ cd python
   $ uv run python -c "
import magika
m = magika.Magika()
res = m.identify_path('../tests_data/basic/python/code.py')
print(f'Model: {m.get_model_name()}')
print(f'Default model: {magika.Magika._get_default_model_name()}')
print(f'Detected: {res.prediction.output.label} ({res.prediction.output.mime_type}), score={res.prediction.score:.4f}')
assert res.ok and res.prediction.output.label == 'python'
"


Phase 2: Wheel Creation & Inspection
------------------------------------
Verify that the wheel packages both the PyO3 C-extension and the standalone CLI binary.

1. Build the release wheel:
   $ ./python/scripts/build_wheel.sh
   $ ls -lh python/dist/
   # Expected: magika-1.0.3-cp38-abi3-linux_x86_64.whl (~22 MB, no redundant model.onnx)

2. Inspect Wheel Contents (Dual-Entrypoint verification):
   $ unzip -l python/dist/magika-1.0.3-cp38-abi3-linux_x86_64.whl
   Verify the two critical files exist:
     - PyO3 Extension: magika/_magika.abi3.so
     - Native CLI:     magika-1.0.3.data/scripts/magika
   Verify removed components do not exist:
     - No magika/cli/
     - No magika/models/

3. Inspect Wheel Metadata & ABI Tags:
   $ unzip -p python/dist/magika-1.0.3-cp38-abi3-linux_x86_64.whl magika-1.0.3.dist-info/METADATA | grep Requires-Dist || echo "No dependencies!"
   # Expected: No dependencies! (True zero-dependency wheel)

   $ unzip -p python/dist/magika-1.0.3-cp38-abi3-linux_x86_64.whl magika-1.0.3.dist-info/WHEEL | grep Tag
   # Expected: Tag: cp38-abi3-linux_x86_64


Phase 3: Clean Environment Testing (Zero-Dependency Validation)
---------------------------------------------------------------
Test installing the wheel into a completely pristine virtual environment with
no development tools or compiler toolchains.

1. Create a clean virtual environment in /tmp:
   $ python3 -m venv /tmp/magika_clean_env

2. Install the built wheel:
   $ /tmp/magika_clean_env/bin/pip install python/dist/magika-1.0.3-cp38-abi3-linux_x86_64.whl

3. Check installed packages:
   $ /tmp/magika_clean_env/bin/pip list
   # Expected: ONLY 'magika' and 'pip' are installed (zero external dependencies).

4. Check installed CLI binary:
   $ file /tmp/magika_clean_env/bin/magika
   # Expected: ELF 64-bit executable (native binary)

   $ /tmp/magika_clean_env/bin/magika --version
   # Expected: magika 1.1.1-dev standard_v3_3
   $ /tmp/magika_clean_env/bin/magika tests_data/basic/python/code.py

5. Check Python library import & detection:
   $ /tmp/magika_clean_env/bin/python -c "
import magika
m = magika.Magika()
res = m.identify_path('tests_data/basic/python/code.py')
print(f'Result: {res.prediction.output.label} (score={res.prediction.score:.4f}, status={res.status})')
assert res.ok and res.prediction.output.label == 'python'
"

6. Clean up:
   $ rm -rf /tmp/magika_clean_env


Phase 4: Forward Compatibility Testing (cp38-abi3)
--------------------------------------------------
Test installing the exact same wheel across multiple Python versions (3.8 - 3.14)
without rebuilding:

   for py in python3.8 python3.10 python3.11 python3.12 python3.13; do
     if command -v "$py" &>/dev/null; then
       echo "Testing with $py..."
       "$py" -m venv /tmp/venv_$py
       /tmp/venv_$py/bin/pip install python/dist/magika-1.0.3-cp38-abi3-linux_x86_64.whl
       /tmp/venv_$py/bin/python -c "import magika; m = magika.Magika(); print(f'$py OK:', m.identify_bytes(b'def foo(): pass').prediction.output.label)"
       rm -rf /tmp/venv_$py
     fi
   done
